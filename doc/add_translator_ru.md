# Добавление переводчика

Локальное расширение разместите в `custom_modules/trans_<name>.py`, встроенный
модуль — в `ballontranslator/modules/translators/trans_<name>.py`. После добавления
файла перезапустите приложение. Обнаружение читает статические метаданные без
импорта реализации; добавлять импорт в `__init__.py` не нужно.

## Минимальный пример

Сохраните [полный пример из основного руководства](how_to_add_new_translator.md#minimal-module)
как `custom_modules/trans_example.py`. Он копирует исходный текст и позволяет
проверить регистрацию, выбор языков и соответствие результатов без API или
модели. Исполняемый пример поддерживается только в основном руководстве.

## Контракты расширения

- Наследуйте `BaseTranslator` и зарегистрируйте уникальное стабильное имя через
  `register_translator`: оно сохраняется в конфигурации. Ключи языков берите из
  `LANGMAP_GLOBAL` в `base.py`, значения `lang_map` — из кодов вашего сервиса.
- `_translate` принимает список строк и возвращает столько же строк в том же
  порядке. Для моделей и API с поддержкой списков используйте `concate_text=False`.
  Объединение допустимо только если сервис сохраняет разделители. Публичный
  `translate()` обрабатывает одиночные строки, пустой ввод и загрузку модели.
- Объявляйте параметры в атрибуте класса `params`, читайте их через
  `get_param_value()`. Переопределяйте `updateParam()` только для изменения
  состояния работающего модуля, сначала вызывая реализацию базового класса.
- Метаданные параметров и языков должны читаться статически. Для асимметричной
  поддержки языков свойства `supported_src_list` / `supported_tgt_list` могут
  возвращать литеральные списки. Просмотр настроек не должен вызывать конструктор,
  инициализацию, загрузку модели или сетевые операции.
- Тяжёлые модели используют `_load_model_keys` / `_load_model` из `BaseModule`.
  Сохраняйте выполнение в рабочих потоках и поддержку headless. Владельцы общего
  LLM-контекста описаны в [руководстве LLM](modules/llm_translator.md).

## Проверка

Выполните [команды из основного руководства](how_to_add_new_translator.md#verification).
Для реального переводчика проверьте метаданные до инициализации, строковый,
списочный и пустой ввод, число и порядок результатов, ошибки сервиса и модели.
В автоматических тестах подменяйте сетевой транспорт. Следуйте
[AGENTS.md](../AGENTS.md#verification) и убедитесь, что открытие настроек не загружает
модель и не обращается к сервису.
