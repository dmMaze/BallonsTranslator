区域合并工具集成完成说明
================================

已完成的工作：
--------------

1. 创建了核心合并逻辑文件
   文件：BallonsTranslator/utils/merger.py
   功能：包含所有区域合并算法，支持垂直、水平、组合合并模式

2. 创建了用户界面对话框
   文件：BallonsTranslator/ui/merge_dialog.py
   功能：提供图形化配置界面，包含所有合并参数设置

3. 修改了主窗口菜单栏
   文件：BallonsTranslator/ui/mainwindowbars.py
   修改：在 Tools 菜单中添加了"Region Merge Tool"选项
   快捷键：Ctrl+Shift+M

4. 集成到主窗口
   文件：BallonsTranslator/ui/mainwindow.py
   添加的方法：
   - on_open_object_manager()：打开文本块管理器（已有占位）
   - on_open_merge_tool()：打开区域合并工具对话框
   - run_merge_task()：执行合并任务（支持当前文件和所有文件）

5. 创建了使用文档
   文件：BallonsTranslator/区域合并工具使用说明.md
   内容：详细的功能说明、使用步骤、参数解释

如何测试：
----------

1. 启动 BallonsTranslator
   python launch.py

2. 打开一个包含 JSON 标注文件的项目

3. 测试打开对话框：
   - 方式1：点击顶部菜单 Tools -> Region Merge Tool
   - 方式2：按快捷键 Ctrl+Shift+M

4. 在对话框中配置参数：
   - 选择合并模式（建议先选"垂直合并"测试）
   - 调整几何参数（可以使用默认值）
   - 点击"对当前文件运行"测试单个文件

5. 查看结果：
   - 合并成功后会显示提示信息
   - 当前页面会自动重新加载
   - 检查文本框是否按预期合并

主要特性：
----------

✓ 支持多种合并模式（垂直、水平、组合）
✓ 支持不同阅读方向（LTR、RTL、TTB）
✓ 灵活的标签过滤规则
✓ 可调节的几何参数
✓ 支持水平矩形和旋转矩形
✓ 批量处理所有文件
✓ 自动重新加载显示结果

注意事项：
----------

⚠ 合并操作会直接修改 JSON 文件，建议先备份
⚠ 不同图片可能需要不同参数，建议先在单个文件上测试
⚠ 目前没有内置撤销功能，建议使用版本控制系统
